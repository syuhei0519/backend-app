# docs の見方

設計上の約束、検証結果、運用・引き継ぎの文書。過去の記録と現在の手順を区別して読みます。

## 構成と入口


主なファイルの入口です。

| ファイル | 役割 |

| [github-migration.md](github-migration.md) | GitHub 移行時に決めた CI と認証・公開の運用記録。 |
| [learning-workflow.md](learning-workflow.md) | Issue・PR・検証記録に残す項目と、ログや生成物の保存方針。 |
